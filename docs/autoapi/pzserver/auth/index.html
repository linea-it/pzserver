Validate and save a token, prompting with hidden input when omitted.

Credentials are stored unencrypted under ~/.pzserver/credentials. On POSIX, the directory and files are restricted to their owner. The home directory must persist for credentials to survive server restarts. An existing credential is replaced only after successful validation.

Existing PzServer instances keep their in-memory credentials.
